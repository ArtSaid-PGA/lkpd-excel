*Masukkan URL Web App dari Google Apps Script agar rekap jawaban otomatis tersimpan dalam Spreadsheet di folder Drive tersebut. Jika dikosongkan, tombol tetap akan langsung mencetak/menyimpan dokumen PDF secara otomatis.

Kode Google Apps Script (Folder ID: 1uNq20snd8-YPiRsyD7AqljU0mctijr-t) 
function doPost(e) {
  var data = JSON.parse(e.postData.contents);
  var folderId = "1uNq20snd8-YPiRsyD7AqljU0mctijr-t"; // Folder Drive Guru
  var folder = DriveApp.getFolderById(folderId);
  var files = folder.getFilesByName("Rekap LKPD Excel Siswa");
  var ss;
  if (files.hasNext()) {
    ss = SpreadsheetApp.open(files.next());
  } else {
    ss = SpreadsheetApp.create("Rekap LKPD Excel Siswa");
    DriveApp.getFileById(ss.getId()).moveTo(folder);
    ss.getActiveSheet().appendRow(["Waktu", "Nama Siswa", "Kelas", "No PC", "Skor Total", "Refleksi"]);
  }
  ss.getActiveSheet().appendRow([new Date(), data.studentName, data.studentClass, data.pcNumber, data.score, data.reflectInteresting]);
  return ContentService.createTextOutput("OK");
}

Panduan Rumus Excel Dasar

1. Aturan Emas Excel

Setiap rumus WAJIB diawali tanda sama dengan (=). Contoh: =C4+D4 atau =SUM(C4:D4).

2. Rumus Penjumlahan (SUM)

Digunakan di kolom Total Nilai (E4 s.d. E7):

=C4+D4 atau menggunakan fungsi: =SUM(C4:D4)
3. Fungsi Statistik Dasar (Kolom C & D)
  • AVERAGE (Rata-Rata): =AVERAGE(C4:C7)
  • MAX (Nilai Tertinggi): =MAX(C4:C7)
  • MIN (Nilai Terendah): =MIN(C4:C7)
